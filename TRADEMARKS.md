The GOVP name, GOVP wordmark, GOVP `G` device and Gemacode name are marks
associated with Brilyetz Holding S.L. and its Gemacode brand.

The Apache License 2.0 applies to the protocol specification, conformance
material, repository documentation and reference software. It does not grant a
trademark licence. The artwork in [`brand/`](brand/) is excluded from that
Apache-2.0 grant and is provided for accurate project identification and
truthful compatibility references.

You may:

- use the GOVP name accurately to refer to the public protocol;
- state truthfully that an implementation is compatible with GOVP when that
  statement can be substantiated against the published conformance material;
- reproduce an unmodified official GOVP mark when linking to or accurately
  identifying this project.

You may not use the GOVP or Gemacode names or marks in a way that implies
endorsement, certification, official status or affiliation by Gemacode or
Brilyetz Holding S.L. without written permission. Forks and modified versions
must not use the official GOVP visual identity as their primary identity.

The canonical assets and their presentation rules are documented in
[`brand/README.md`](brand/README.md).
